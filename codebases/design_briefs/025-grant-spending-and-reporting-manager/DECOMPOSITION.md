# Grant expenditure and reporting ledger

Grant reporting is organized around funding tranches and service periods. The program first resolves each amendment's effective interval, then derives the condition set that governs the requested reporting window. Expenditures are split only using an authorized allocation basis and their actual service dates. A shared activity link is reconciled before cost attribution, so shared funding can remain legitimate while duplicate attribution is blocked. Milestone evidence distinguishes delivered activity from demonstrated impact; narrative claims are built from accepted activity evidence and their conditions. Personal data disclosure runs on a separate consent-and-authority path. Submission is an immutable artifact version whose approval and actual funder receipt remain distinct; a correction appends a new version linked to the original receipt.
