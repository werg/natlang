# Replication planning workbench

The workbench recovers the reference procedure from versioned sources and preserves paper/code disagreement as competing interpretations. Dependencies are a graph of exact inputs, resources, versions and expected artifacts; unavailable components remain blocked or explicitly adapted. Missing random seeds require a sensitivity set declared before outcomes. Dataset content hashes distinguish exact reproduction from an adaptation. Only resolved method steps compile into an execution plan.

Execution evidence is read from typed job receipts. A crashed run is incomplete until every expected artifact and provenance binding is verified. Outcome comparisons require complete jobs tied to source, dataset, environment and seed. Prose/code conflict, an unavailable dependency, changed dataset, omitted seed, or partial output cannot be smoothed into a claim of exact replication.
