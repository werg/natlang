# Quality escape investigation design

This program follows defect genealogy rather than a generic task pipeline. It keeps rework branches and process revisions distinct while tracing exposure, then places each defect observation in the inspection regime that actually detected it. Causal review compares competing mechanisms against both supporting and contrary evidence and explicitly prevents an operator name from becoming a blame conclusion. Containment is reconciled against unit-level holds, so partial release does not erase the held remainder. A recurrence after closure reopens the causal assertion and requires a fresh effectiveness test.

The typed input contains only case-local process histories, lot lineage, inspection methods, holds, action records, and supplied evidence. Missing lineage widens the uncertainty boundary. The proposal remains non-committing; authorized lot disposition, corrective work, and external notification belong to the accountable quality system.
