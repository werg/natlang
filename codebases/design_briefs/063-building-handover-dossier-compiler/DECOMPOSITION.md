# Building handover dossier design

The compiler binds artifacts to installed asset identity and variant, not to a familiar model name. It selects only the manual sections that apply to the installed variant, rejects a certificate addressed to the wrong asset ID, and distinguishes a permission-backed durable archive from an expiring portal link. When source formats cannot be opened by facilities staff, it requests an approved accessible export while retaining the original. Temporary arrangements retain their expiry and named follow-up owner so the obligation survives the handover.

The package is ready for human acceptance only when each required artifact and continuing obligation has a supported match. Archive, conversion, and follow-up actions remain proposals until the facility host records their completion.
