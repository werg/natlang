# Decision-dependency ledger

## Premise graph and versioned owner resolutions

The durable object is an append-only decision/premise graph. Meeting acts establish decisions; counterfactual links establish premise dependence; source changes reopen only an affected interval. The root follows a correction frontier, not a stage-result pipeline. Necessary descendants and explicit cycles are retained separately from supporting or independently justified work.

An owner response is a separate public operation. It binds the exact pending question, decision revision, authorized signer and adopted meaning. Stale concurrent responses carry the intervening change back to the reviewer. Successor assignment changes review routing without rewriting historical authorship. Restricted supporting sources remain opaque markers in the user projection. Repeated copied notes never add independent support.

## Verification boundary

The original domain records, five semantic gates, five operational scenarios, and independent finite gate answers remain the contract. Public operations and checkpoints belong to this application. Native loading and source-call inspection do not prove learned execution quality. Effect intent is distinct from an authorized receiver receipt.

The public operation constructs its complete typed carried state on every return, including blocked and no-change outcomes. Only the domain-specific observed change updates its own fields; prior receipts, unrelated history and unresolved external outcomes remain inspectable. Guardrail findings are consumed by the result or the action eligibility they govern.
