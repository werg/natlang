# Clause package designer

Negotiation begins with issue positions keyed by party and mandate: preferred outcome, authorized fallback, and prohibited concession stay distinct. A clause dependency graph connects definitions, triggers, exceptions, remedies, caps, and cross-references; package candidates are combinations over that graph, not independent edits. Each package records retained protections and traded concessions so interactions can be compared. Redlines are classified by semantic effect, and conditional assent remains attached to its prerequisite. External rendering strips comments into a separate artifact while the protected note record remains intact. Undefined terms block package circulation. Approval attaches to the exact rendered hash; any change after signature forces a new approval lookup. The offer is only a proposed outbound artifact, never evidence of counterparty acceptance.
