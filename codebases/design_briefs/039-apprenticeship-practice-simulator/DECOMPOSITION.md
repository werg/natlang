# Apprenticeship practice simulator

The simulation preserves the child classifier's kind, intent, and target as returned data. Questions use the actor's visible facts and return without advancing the world or checkpoint; ambiguity from either classification or procedure matching returns an explicit clarification with the same no-mutation boundary. Only actionable proposals reach world advancement. Their checkpoint stores a complete turn receipt bound to the original source, world, actor, procedure, and action history; a matching retry returns the recorded interpretation, action, transition, challenge, and debrief while preserving the current later checkpoint. A legacy applied or seen ID without its receipt remains unresolved. Debrief records planned action, simulator transition, and observed learner-action history separately, so a plan alone cannot be presented as performed evidence.

World advancement checks resource and procedural invariants before replacing the prior state. Unsafe behavior is refused or handled under the approved training scenario, without invoking a real control. Challenges are selected from the objective-specific catalog using a saved seed, filtered for repeat exposure, and checked for a discoverable recovery route. Debrief traces each finding to observed action IDs and distinguishes process quality from a fortunate or adverse outcome. Session checkpoints preserve prior state, actor knowledge, and challenge lineage for a later invocation.
