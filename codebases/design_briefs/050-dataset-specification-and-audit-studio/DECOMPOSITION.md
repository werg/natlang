# Dataset specification and audit studio

## Use-bound editions and source-family lineage

The studio has two routes: adjudicate a prospective edition, or withdraw consent from an already tracked source lineage. It does not treat annotation, eligibility, diversity and release as interchangeable passes. Label observability can force a task revision before annotation; disputed source identity changes independent-source counts and split closure before release.

The source-family graph groups copies and shared worlds without claiming they add independent evidence. Eligibility is evaluated for the requested release audience and use, not a generic license flag. Exact counts operate on the admitted family IDs. A frozen edition binds use, annotation rules, permissions, splits and owner approval; withdrawal follows descendants to artifacts and downstream notices and records actual removal receipts separately.

## Verification boundary

The original domain records, five semantic gates, five operational scenarios, and independent finite gate answers remain the contract. Public operations and checkpoints belong to this application. Native loading and source-call inspection do not prove learned execution quality. Effect intent is distinct from an authorized receiver receipt.
