# Tender Response Factory

A tender response is a frozen, version-addressed bundle whose obligations come from the main tender, schedules, forms and ordered addenda. Each clause is classified as eligibility, scored preference, conditional instruction, format, or attachment; every obligation links to a response slot or an explicit nonresponse decision. Capability matching is against verified edition and scope, not adjacent features or future intent.

Technical, financial and delivery contributions are commissioned by requirement and owner, then reconciled against one authoritative quantity schedule before cross-section response text is drafted. Certificate validity is evaluated at performance start. A deterministic bundle validator provides a typed artifact binding exact file set, names, sizes, forms, addendum revision and response hash; NatLang does not claim to run portal size or hash computation. Approval binds that hash. A timeout is resolved by tender identity and idempotency key readback, and status remains unknown until an authoritative acknowledgment matches the frozen hash.
