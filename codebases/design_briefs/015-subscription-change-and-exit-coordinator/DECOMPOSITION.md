# Subscription Change And Exit Coordinator

The request's target set is a named subscription collection; add-on removal and account closure are different intents. Consequences come from authoritative entitlement and billing receipts, and current near-renewal timing must be resolved against service timestamps and configured cutoff rules. Reseller-controlled entitlements and shared-workspace access create separate owner actions.

Choice construction keeps the directly requested permitted exit visible and never preselects retention. Consent is bound to exact option, subscription IDs, date, account version and scope; any change makes prior consent stale. Execution state is reconciled against immutable operation receipts, with pending refunds kept separate from service status. Partial linked-product results remain partial until all match the selected option. Only a state comparison and durable receipt can establish completion; a cancellation request is not a completed exit.
