# Organizational knowledge integration workbench

## Operational substitution across organizational boundaries

The core is a context-indexed sense map with two-direction substitution witnesses. The program retains organizational dialects when replacing a term changes the actor, record, obligation or completion condition. Meaning bridges feed role handoff scenarios; a shared label cannot erase an unowned approval or responsibility.

Only reversible record families with actual exact integrity receipts and preserved semantic round trips enter a migration wave. A refused shared definition retains its boundary. Historical organization aliases stay searchable. Personnel restrictions produce role-level agreements, not inferred employee identities. A separate rescheduling operation changes planned execution dates while preserving already effective decisions and completed waves.

## Verification boundary

The original domain records, five semantic gates, five operational scenarios, and independent finite gate answers remain the contract. Public operations and checkpoints belong to this application. Native loading and source-call inspection do not prove learned execution quality. Effect intent is distinct from an authorized receiver receipt.
