# Policy change simulator

This application never generates simulation outcomes. It first binds two named policy versions and a frozen cohort. Each historical case is complete or indeterminate; deduplication edits are cohort changes, not policy effects. Comparison accepts only exact paired baseline and candidate execution artifacts with equal input digest and engine configuration, distinct execution identities, and content-bound policy versions. Missing receipts block comparison.

The result comparison reads supplied outcome, duty, permission, timing and escalation fields and traces differences to changed clauses only where evidence supports the link. Rare exceptions are inspected individually before boundary descriptions or options are prepared. Untested combinations remain unknown. A candidate edited mid-run forks the evaluation; adoption pins only the exact tested hash, and later edits require another complete replay.
