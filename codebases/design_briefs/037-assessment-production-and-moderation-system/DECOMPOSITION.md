# Assessment production and moderation system

`freezeAssessmentEdition.nl` begins with competency-to-evidence mapping, then drafts items and checks whether the supplied context actually permits a response. It builds scoring criteria around demonstrated competency, enumerates valid alternative methods, and sets partial-credit boundaries before an independent solve sees the item. Blind solutions and borderline response replays feed a repair loop; both prompt and rubric are rechecked together.

Exposure handling preserves the historical edition and response links while quarantining a confirmed leak from future assembly. Appeal review binds to the exact rubric version. A changed rubric identifies the full scored cohort, including learners who did not appeal, but leaves all grade changes pending an authorized moderator. An erroneous key or unresolved answerability defect blocks release and surfaces any controlled regrade dependency. Content equivalence and timing accommodations remain separate constraints. This source proposal does not itself publish an edition or alter grades.
