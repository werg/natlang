# 097 — Live Event Disruption Director

## Source-derived procedure

Five domain stages: recoverEventPromises, interpretFailure, generateFormats, rebuildRunOfShow, coordinateLiveChange. Each stage has a bounded evidence preparation step, field-level decision, typed draft construction, and independent audit. Ten cross-cutting procedures frame scope, select authority, plan dependencies and evidence, reconcile collections, resolve questions, propose bounded repairs, prepare review, compose a recipient-specific view, and assess the impact of source deltas.

## Domain algorithms and gates

- **recoverEventPromises** — Reconcile agendas, contracts, accessibility needs, and participant communications to identify commitments that matter. Distinguish published promises from internal preferences and preserve dependencies such as travel, technical setup, and required access arrangements. Gate: Commitment priority follows supplied authority and actual promises.
- **interpretFailure** — Read staff reports and provider updates to determine what capability is lost and which parts of the program are affected. Separate confirmed facts from estimates and avoid assuming a missing person or resource will return by a convenient time. Gate: Disruption scope and uncertainty are explicit.
- **generateFormats** — Invent alternative formats, sequences, or uses of available resources that preserve essential outcomes. Consider remote participation, moderated alternatives, or resequencing where approved, and disclose changes affecting access, consent, or contractual commitments. Gate: Alternatives preserve hard safety and accessibility constraints.
- **rebuildRunOfShow** — Use exact scheduling and resource checks to construct a revised run of show with owners, dependencies, and decision deadlines. Reserve resources before announcing changes, preserve crew readiness, and identify points beyond which a contingency is no longer feasible. Gate: No double booking, impossible setup sequence, or unsupported timing promise.
- **coordinateLiveChange** — Obtain producer approval, issue role-specific updates, and confirm that critical staff received the same revision. Track actual execution and adapt only affected elements as new events arrive, preserving an authoritative current run plan. Gate: Safety authority, staff acknowledgment, and public communications align with the current plan.

## Action boundary

The natural-language program produces a proposal for accountable review. Authorization, persistence, and external effects are exact host responsibilities. Evidence gaps and conflicts stay visible; no action is inferred from fluent completion.
