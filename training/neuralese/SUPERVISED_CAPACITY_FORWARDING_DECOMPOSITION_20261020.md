# Supervised continuation capacity

The natural-language production policy is to keep useful training advancing and
admit new data with capacity evidence for the actual runtime and hardware.
Restoring optimizer progress alone does not establish that evidence.

1. Resolve the current stage and its declared parameters (existing recipe function).
2. Forward its explicit memory qualification requests to the actual trainer
   (one instruction in the existing supervised continuation function).
3. Let the restored trainer verify the bound requests and produce its resident
   geometry certificate (existing exact numerical/capacity mechanism).
4. Admit new rows using that certificate and the existing resident transaction.

The crisp change removes a parameter-dropping shortcut. It introduces no new
policy selector, prompt, qualification bypass or inferred historical credit.
Verified certificate reuse is a separate optimization; an absent certificate
must never be treated as inherited merely because a parent was restored.
