# Qualify the actual shared semantic objective

The supervisor progresses ready models through the entire VAE, joint and
distillation recipe. Exact numerical and capacity checks serve that progression;
an individual SFT certificate does not qualify the different joint objective.
The policy remains the existing natural-language supervisor/readiness program.
The work below is exact gradient, state-preservation and update plumbing.

1. Route every selected participant through one existing
   `ParameterCotangentScope`, spanning the complete bidirectional objective and
   its backward. Do not nest scopes or step a participant before the complete
   model/VAE adjoint has finished. Use a named module container over the actual
   models, without copying weights or changing their local parameter identities.
2. Give the existing semantic producer and consumer paths an explicit reference
   execution option, applied to every model call including payload baselines.
   The reference must execute real cached graph semantics with the same VAE
   noise, models, controls, consumer losses and distillation targets.
3. Before a new phase or changed numerical profile can update parameters,
   compare the actual objective and every declared trainable derivative across
   both models and the VAE against the exact reference. Extend the existing
   complete-gradient comparator for an objective without a separate raw input
   embedding argument; do not invent an unused input to satisfy its interface.
4. Preserve RNG, backend state, optimizer state, parameter values, existing
   gradients, exposure and update counters across qualification, including
   exceptions. Record actual participant/objective/runtime identities and
   numerical measurements. Retain failed evidence and diagnose divergences.
5. Bind real whole paired-source capacity measurements to their complete source
   and phase geometry. Run the qualified forward and backward without optimizer
   updates. New source geometry or profile changes must be resolved explicitly,
   without treating an unrelated SFT capacity proof as joint evidence.
6. Save resumable phase qualification alongside the existing semantic training
   state and refresh obligations. Resume real progress rather than resetting
   history. Do not delay a usable VAE phase for a later joint-only check, and do
   not let a metadata flag substitute for executable phase-boundary checks.
7. Validate real hybrid/attention paired objectives, both model gradients,
   producer/consumer fan-in, VAE gradients, BF16 cotangent routing, exact
   interrupted continuation, and failed qualification with zero updates. A
   separate integrated review is required before cloud cutover.

Implementation is developed off the active runtime. No trained adapter,
production numerical qualification or readiness credit is claimed by this plan.

The phase gate measures one complete cached-reference derivative comparison for
each participating model subset and actual whole backwards for the source's
Pareto frontier of producer, payload and rewritten consumer geometry. Geometry
coverage is recorded as geometry coverage; it is not a guarantee that every
unmeasured trajectory has identical memory demand. All gradients remain live
through global clipping, matching the joint optimizer path rather than SFT's
per-parameter release path. Failed measurements retain their full subproofs and
grant no phase/exposure credit.

The resumable profile includes the complete runtime inventory, model and backend
execution settings, trainable/dtype geometry, source, objective, PyTorch/CUDA and
actual device/precision settings. The process runs immutable loaded code; a code
change is adopted by continuation in a new worker. Layout discovery enters the
selected backend dispatch; held evaluation retains its existing native serving
path. Qualification restores the exact empty-gradient update boundary, all
optimizer parameter/moment versions, backend counters/scales and RNG.

Local verification: actual two-model objectives in all three phases, BF16
backbones with the production optimizer policy, retained-gradient capacity,
failed proof persistence, runtime-change invalidation and exact interrupted
continuation pass. Existing complete-gradient/cotangent CPU regressions and
whole-policy continuation checks pass; CUDA-only cases are explicitly skipped
in that CPU regression invocation. Target-hardware measurements remain mandatory
at the cloud phase boundary. These local checks do not grant cloud readiness.

Independent review found that the policy branch skipped the phase gate. Extend
the same objective boundary, complete comparator and retained-gradient capacity
mechanisms to complete authenticated policy episodes. Pass the explicit cached
reference through every native segment and codec target baseline. Scan actual
admitted policy episode geometry once per bound source/profile and qualify its
frontier, retaining a derivative representative of each active participant set,
objective mode, advantage sign and communication kind. Keep source rewards, actor/codec history
and update/exposure counters immutable. This is exact execution plumbing for the
existing curriculum, not a new curriculum policy or a text-only RL substitute.

Policy extension verification: 65 focused CPU cases pass across the complete
phase checks, real heterogeneous-tokenizer codec episodes, gradient routing and
semantic continuation. A further real CPU curriculum executes VAE, joint,
distillation and two complete policy updates, and matches every model, VAE,
optimizer and RNG tensor after interruption/resume. Its Mellum FP8 production
certificate remains false on CPU; the CUDA-specific test remains explicitly
skipped. No target-hardware qualification is inferred from these checks.
