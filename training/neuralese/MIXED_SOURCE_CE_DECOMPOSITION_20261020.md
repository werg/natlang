# Exact CE objectives within mixed admitted sources

The training policy is to balance the context and target mass of ordinary raw
rows while preserving existing segmented whole-trajectory and native graph
objectives. A source container can contain both: its first row cannot decide
all later rows. Data admission, protected splits and earned exposure are separate.

1. The supervisor declares the complete actual source DAG and the exact raw
   context coefficient through the existing CE policy builder.
2. A source-bound mixed-row encoding selects the already existing ordinary or
   witnessed-pair decoder from the authenticated row's explicit provenance.
   Existing segmented objectives and direct native node objectives are retained.
3. Crisp verification checks source identity, ordinary suffix/coefficient/raw
   masks, witnessed producer/consumer provenance and every zero exclusion. No
   coefficient or target boundary is inferred from a threshold.
4. The shared consumer applies the existing mass law. Held measurements resolve
   the same row encoding without adding training exposure. All graph nodes,
   IDs, source bindings, optimizer/RNG state and past row credits remain intact.
5. Preparation reports the exact source set and explicitly distinguishes an
   encoding contract from a full row census. Runtime validation remains active
   for every consumed row; an unsupported raw coefficient still fails closed.

This is exact objective plumbing, not a new scheduler, trainer, parser or model
prompt. Existing policies keep their original semantics until an explicit
continuation selects the new encoding. No frozen runtime is edited in place.
