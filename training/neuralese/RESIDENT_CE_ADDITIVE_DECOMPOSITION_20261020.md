# Live source addition with preserved CE intent

Policy: continue useful training on newly admitted sources while retaining the objective of every already admitted row, all held declarations and failure masks. This is a data continuation, not permission to change prior supervision.

1. Authenticate both declared CE policies through the existing loader and the existing recipe CE continuation law.
2. Require each prior source declaration unchanged; preserve every other policy field except the source-contract inventory. Require contract semantics unchanged and bind its complete active leaf set to the actual new train DAG. Reject held overlap, missing declarations, coefficient/mask changes and undeclared inventory changes.
3. Retain the resident's normal predecessor, geometry, class, held, owner and index checks. Prepare the new loaded policy before the sole source commit and recheck both immutable policies at commit. Publish the loaded policy together with the new resident state.
4. Before making the next batch, the shared trainer adopts that already authenticated policy, records the binding transition at the actual update boundary and keeps optimizer, RNG and exposure untouched.

The policy is expressed here in natural language. Crisp helpers authenticate immutable JSON/artifact identities and perform the existing atomic resident transaction; no new model interface, prompt, runtime feedback, source parser or numeric objective is introduced. Both backbone ports use the same path. CPU tests exercise real model updates and compare parameters, optimizer/RNG/exposure against an explicit continuation; these do not qualify GPU arithmetic or activate a frozen runtime.
