# Continue useful SFT after incomplete foundation readiness

Policy: retain actual failed runtime/task readiness and continue useful supervised
work. A completed exposure cohort grants neither task readiness nor RL/VAE release.

1. Publish the genuine newly earned checkpoint and keep its exact readiness report.
2. If foundation qualification is incomplete, clear prior readiness authority and
   retain the failed report as repair evidence, without changing exposure/debt.
3. Finish useful remaining supervised stages. If current foundation qualification
   is still absent, begin a fresh SFT cycle rather than collecting a policy round.
4. Request positive refresh updates on the next foundation attempt. Once a genuine
   report qualifies the current weights, the existing RAW/RL schedule may proceed.

The existing recipe/curriculum owns this policy. Crisp helpers verify checkpoint
identities, preserve the report binding and atomically commit the existing cursor.
