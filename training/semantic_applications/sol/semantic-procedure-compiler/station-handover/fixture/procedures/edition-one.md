ID E1. CC adopted edition ONE on day0, effective day0.
[V1] Edition ONE permits a named operator to start a transmission when that operator owns the station token and has an accepted queue turn. ONE does not require a separate safety acknowledgment.
[CUSTODY] There is one station token ST. Only its current actual holder has custody. A witnessed completed handover changes holder; a proposed transfer does not. Appearance of a similar brass token is not identity with ST.
[HAZARD] A known uncleared station hazard blocks starting a transmission under every edition. An unresolved decisive hazard finding leaves permission unresolved. Only an actual signed clearance by maintenance M establishes clearance.
