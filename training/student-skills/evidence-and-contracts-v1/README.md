# Evidence and contracts skill candidate

An alternative four-topic library for controlled developmental comparison with
`task-workflows-v2`. Not a replacement or a demonstrated improvement.

Topics group actual failure mechanisms: hidden input values/pagination; exact
query scope; claim polarity and group comparisons; callable and return contracts.
Descriptions identify observable need rather than a failed-run label. Bodies
are short, action-oriented, and omit invented runnable placeholder identifiers.
This changes topic boundaries and library size together; outcome differences
cannot isolate those factors. Measure discovery, repeated reads, actual application,
task success and request cost separately. A forced-read arm tests helpfulness more
than discoverability; no extra reads alone count as an improvement.

Do not automatically add skills to ordinary training. Require fresh replay and
reviewed helpful-use demonstrations, including inventory-present/no-read controls.
