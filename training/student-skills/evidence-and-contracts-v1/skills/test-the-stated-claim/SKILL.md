---
name: test-the-stated-claim
description: Use when a boolean claim involves negation, exceptions, every group, or a comparison whose scope could change the answer.
---

Write down what would make the stated claim true and what would refute it. Preserve negation: a false positive statement can make its negated statement true. For "every group", test each group; an overall aggregate is not a substitute. Apply exceptions before deciding. A boolean question is a proposition to evaluate, not an asserted fact. Return true exactly when the stated proposition holds. A false result is a successful answer; report blocked only for genuinely missing required evidence.
