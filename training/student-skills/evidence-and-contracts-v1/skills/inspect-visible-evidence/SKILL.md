---
name: inspect-visible-evidence
description: Use when a scope listing shows types or a preview hides values needed to answer. Inspect the needed evidence once.
---

A type listing is not the argument's value. Use eval to inspect the actual variables already declared in this call. Log the fields needed for the question. A shortened preview does not mean the remaining rows are absent: the variable still holds them. For a paginated source, inspect its declaration, then gather every relevant page before claiming a global maximum or total. After obtaining the evidence, compute or answer; another documentation read is not progress.
