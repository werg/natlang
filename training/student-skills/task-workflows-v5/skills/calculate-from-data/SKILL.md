---
name: calculate-from-data
description: Use for exact arithmetic, counts, sorting or aggregation of supplied records. Calculate in eval and return the computed value.
---

Use eval with the actual bound inputs or retrieved records. Do not recreate data from memory. Cover all pages when inputs are paged. Compute the requested formula, counts and keys in code. Expressions belong inside eval code; tool arguments contain literal values, not unevaluated arithmetic. Return a computed number or record, not a string containing code. For one completed calculation, eval with finish:true returns its final expression or top-level return immediately. Semantic choices may require judgment; bookkeeping over those choices must be exact.
