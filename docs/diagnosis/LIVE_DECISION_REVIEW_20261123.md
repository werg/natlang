# Conservative decision review for a completed live goal

A goal can succeed while individual model decisions are wrong. Archive wave0036
actually committed the requested project and its retained contents passed the
independent Terra review, but a rejected oversized return triggered a redundant
permission interpretation and a false final hold. The original139provider replies
remain evidence. Declaring only its last return incorrect would still train the
bad intermediate interpretation.

Inventory: `live_teacher_sources.declared_return_exclusions` can mask the final
return of an exactly bound returned value. It cannot express a bad action or an
intermediate premise not present in the final result. `observed_training_turns`
selects approved live decisions for every SFT/fill consumer; `sft_sources` and
`filled_reasoning` reload that source. The independent disk verifier in
`ts-host/scripts/observed-workspace-evidence.mjs` recomputes live eligibility.
`native-materializer.ts:materializeNativeRows` deliberately rejects ordinary
NativeDecisionHold overrides for observed workspace captures: their admission
belongs to this independent live proof. All actor engines subsequently consume
the same approved per-call targets; no engine execution or sampling law changes.

An optional proof `decisionReview`, schema `natlang.live-decision-review/1`, lists
only excluded generations. Each declaration names the exact captured call ID,
full definition, original call-file SHA256, generation ordinal and a nonempty
reason. Both readers independently require all selectors to match, reject
unknown/score/duplicate generations, and recompute the denied training flags.
The proof and its checker/evidence bindings remain part of the original-bound
whole-outcome reassessment. The native trajectory records these exclusions; all
requests, replies, effects and original verdicts remain unchanged. This mechanism
cannot promote a decision, fabricate a replacement answer or turn a failed goal
into a success. Whole-goal completion still needs independent native and semantic
proof. A completely masked demonstration is evidence without training targets.
