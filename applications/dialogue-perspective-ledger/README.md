# Dialogue Perspective Ledger

A read-only directory reducer over a closed fictional conversation. Twenty-nine connected callable NL
functions separate quotation attribution, original deictic time, speaker force, participant receipt,
endorsement, verified knowledge, conditional promises and adopted correction. Every semantic stage uses
numbered natural-language pseudocode. TypeScript contains declarations only.

The original Portico packet contains 11 nested documents, 43 connected clauses, five participants and
16 perspective/time queries. The first source has native loader/type checks. Its private oracle currently
contains query invariant projections; a full typed canonical report and exact checker are still pending.
No application execution, live literal consumption or training admission is claimed.
