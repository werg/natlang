# Witness Rewrite Studio

A natural-language application for revising a selected story while preserving character information, physical objects, action motivation, dramatic callbacks and unresolved motives. Its 27 callable modules own separate semantic transformations and reuse departments through explicit `uses`.

The first harbor fixture removes a letter delivery. A successful three-scene repair replaces it with oral testimony, updates the later acquisition claim and keeps the reconciliation meaningful. Seven authored proposals include plausible but invalid alternatives. The exact source and patch service verifies identities, hashes, quotation spans, allowed paths and nonoverlap; it makes no narrative decisions.
