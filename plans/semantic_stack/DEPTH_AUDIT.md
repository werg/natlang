# Semantic application depth audit (2026-10-14)

The owner wants connected natlang applications comparable in scope to the larger
existing application trees. The domain decision procedure must be deep,
numbered natural-language pseudocode. File count, stage count and teacher
success cannot substitute for that source property.

## Existing catalog versus authored applications

- `training/semantic_stack/sol_programs.json` (100 designs) and
  `plans/semantic_stack/astra-programs.json` (120 designs) remain useful task and
  fixture sources. They are not 220 qualified application-scale programs.
  The sampled Sol entries 001–007 use the same four-stage call path and the
  same finite-frontier/literal scaffold with a short domain-specific objective.
  That scaffold needs authored, domain-specific `.nl` procedures and a live
  typed-handoff trace before any such entry earns the application-scale label.
  The Astra designs specify more distinct stage outlines and source worlds,
  but the catalog itself is still a design rather than a completed source tree.
- Seed Lineage Laboratory and Cave Mission are authored source trees with
  different branches and typed semantic handoffs. Their exact source replays
  and independent reviews establish source readiness, not live or training
  admission. Cave's prior live diagnostic hit the Codex output-ceiling
  transport bug; reseal after its fix and inspect the substantive later stages.
- Ecology has reached a real nested Stage 5 live trace, but v15d assigned
  per-entity graph findings in case-specific JS. Keep it held. The next source
  must ask a scoped NL callable for each node's status and reason, consume its
  typed result, and leave only exact traversal and sign arithmetic to code.
- Dialogue Perspective Ledger and Turn Window Mirror Garden are undergoing
  authored-source and typed-handoff review. Their source depth is a claim
  until live execution shows child judgments alter later state and output.

## Review for each new source revision

Trace one complete input across several different branches. For every branch,
record (1) the records and state it owns, (2) its numbered NL decision steps,
(3) the exact typed child or scoped-literal result consumed, and (4) the later
state/output field that changes because of that result. Inspect any model-authored
JS in the live trace: exact mechanics are fine; a case-specific answer table or
domain status assignment is a source/agent ergonomics failure to repair.
Preserve correct small examples in the ordinary mix. Record the live trace and
independent semantic witness before training admission.
