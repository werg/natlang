# Passive call-value observation

Before-edit inventory: calls/snapshot.ts snapshot/portable/typeLabel read getters via Object.entries/index/constructor, call toJSON through JSON.stringify, and invoke arbitrary conversion for nonportable previews. inputFeatures uses Object.entries/array.slice. calls/normalize.ts inputLeaves does the same for approachHash and mining. calls/recorder.ts setInputs spreads and enumerates values/captures before snapshotting. These are observation, not application execution: none may evaluate accessors or conversion hooks.

Shared consumers: recorder.ref covers inputs/captures/outputs/effects/folder readbacks/code revisions; recorder.setInputs computes features; recorder.finish computes approachHash. calls/index.ts exports snapshot/features/normalize; calls/mining.ts uses inputLeaves for offline recorded arguments. All platform SDKs compile these exact modules. Existing calls:false remains the recording opt-out. Managed llama, wllama, Python and SGLang only produce provider responses; they do not snapshot arbitrary JavaScript values or own call-store serialization. Their request JSON encoding is application transport and is not changed by this observation-only fix.

Implementation: serialize only own enumerable data descriptors of portable plain objects and dense arrays, using primitive-only JSON encoding. Never invoke toJSON, object conversion, array methods, constructor getters or property getters. Feature/normalization walks skip accessors rather than invent values. Recorder explicitly marks an accessor input nonportable and keeps actual data inputs unchanged. Cross-realm plain records remain supported. Proxy reflection traps cannot be inspected without invoking proxy internal operations in ECMAScript; this change does not claim to make arbitrary Proxy objects side-effect free.

Validation: official Node build passed; 42 focused call snapshot/record/Std/persistence/replay controls passed (6.5s/608MiB). First attempt had one test fixture missing required finish.detail; corrected fixture, product source unchanged. Added an actual std result identity/accessor control before final check. Snapshot bytes/hashes for ordinary JSON and cross-realm records are unchanged; opaque previews no longer execute user conversion. Excluded values retain only primitive type classification. No physical browser/Workerd host or model-provider probe was run.
