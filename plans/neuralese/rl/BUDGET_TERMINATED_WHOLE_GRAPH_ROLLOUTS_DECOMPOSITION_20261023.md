# Whole-graph RL for terminal model-request-budget failures

## Production finding: historical case-wall cancellations

The archived LF `round-000003` collection is not a model-request-budget example. Its eight result-less samples end with `case_wall_budget`; worker accounting says `partial_without_terminal_result`, and their interrupted snapshots say `This operation was aborted`. They retain hashed partial evidence and captured raw-call frames, but have neither the exact model-budget terminal error nor `record_binding_verified` receipt needed for model-caused credit. Keep them unscored. The actual root-cause guard is the scorer's existing `reward=None` for host case-wall stops and the rule that a result-less rollout with no verified budget prefix gets no training reward. This prevents empty native graphs from entering training without upgrading cancellations into policy failures or samples.

I replayed the archived round in `/tmp/luna-lfm-budget-prefix-real-round3-20261023` under an isolated output path. The scorer emitted all 16 rows: eight case-wall cancellations had `reward=None`, `unscored=budget_exhaustion`, and empty turns/graph; eight completed result rows preserved their saved turns and execution graphs exactly. None of the cancellations was trainable. The additional model-request-budget prefix path below remains a separately authenticated capability, validated with source-bound fixtures and collector-schema evidence; it was not observed in those archived case-wall rows.

The policy is: an exact, source-bound `model_request_budget` failure is a model-caused zero-reward episode. Its already observed sampled actions may train only when the collector's durable partial evidence proves the complete captured policy-turn prefix and its complete observed execution-graph prefix. Host `case_wall_budget` and other host stops remain unscored. No partial or failed episode may imply a task result, successful completion, held-data eligibility, or unobserved model action.

1. The queue collector owns exact outside-world task, source, result/error, and partial-evidence files. A crisp admission helper verifies the source row against the current prepared packet path and digest, requires the source-accounting digest and terminal-error receipt to match that packet, rejects duplicate job-state matches, and verifies the immutable partial job, evidence-manifest bytes and hashes, and one exact terminal budget reason. It imposes no arbitrary sidecar byte ceiling; verified captured frames remain available at their actual size.
2. The scorer turns authenticated `teacher_action_frame` evidence into the existing rollout-turn representation, preserving the original requests, raw replies, actor/sampling receipts, and actual invocation IDs. It derives graph events only from the recorded interrupted execution snapshot. No event or action is reconstructed from text, task intent, or a later outcome.
3. Existing `episode_graph` and `native_occurrences` verifiers decide whether the partial turn/edge inventory is complete. Existing `native_replay.compile_replay` reconstructs the exact sampled-plus-forced token stream, occurrence-bound producer dependencies, and differentiable whole graph. If any capture is incomplete or ambiguous, the attempt stays unscored and is retained as evidence.
4. The S7 natural-language policy defines exact model-request-budget exhaustion as a model-caused zero and permits its verified observed prefix only. Existing `native_replay.prepare_objective` applies that reward to the validated prefix and the shared trainer performs the update. Crisp changes are limited to provenance verification and score plumbing; the policy does not synthesize a task result or turn.

The native terminal-error schema binds source/program/index and the error file digest but does not carry a separate execution-attempt identifier. Attempt identity is therefore checked within the partial snapshot, request-attempt list, evidence manifest and all action-frame records; the scorer does not invent a cross-file attempt field absent from the collector receipt.

This is a narrow repair for result-less model-request-budget terminal errors. It does not admit wall-clock timeouts, cancelled/in-flight attempts, transport failures, held rows, or incomplete graph prefixes.
