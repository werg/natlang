# Independently certified calls from failed live goals

Automatic salvage is opt-out (`VIBESTUDIO_NATIVE_PARTIAL_SALVAGE=0` or collector/exporter `--no-partial-salvage`). It preserves the complete original failed packet and all captured calls. It does not turn the goal into a success. Only a registered complete native return contract can select a pure call subtree. Unsupported domains remain raw; terminal execution, schema validity and successful API calls alone are insufficient evidence.

The initial hooks cover GAD's complete durable-question judgment and participant judgment, across its 24 unchanged worlds. They bind the native history/roster, original native check, entire expected return, exact captured inputs/output, actual callee instructions/source, and source-hashed assessor. The actual archived retired-question failure yields one correct interpretQuestion decision; the incorrect evaluateRoster answer is excluded. Root and whole-goal failure remain unchanged.

The format is `natlang.training-scope/2`, with `natlang.independent-native-return/1` certificates. Python load_episode and the Node disk verifier independently validate source/capture/native bindings before the materializer admits decisions. Legacy scope/1 remains supported but cannot carry new certificates. Old production reader 2a877c1b rejects scope/2 with `invalid partial live training scope`, admitting zero decisions. Deploy the new reader to export, ingest, fill and training before registering any new automatic partial cohort. No cohort was registered by these checks.

Inventory before editing: live collector/exporter and their CLI/schema consumers; Base application-outcome/review/invocation contracts; 101 SST outcome producers; Python live_teacher_sources, live_campaign_ingest, reassessment/recheck/campaign; Node disk verifier and materializer. Existing ingest/campaign/SFT already distinguish partial episodes from completed goals and consume only selected decisions. No engine/model wire changes are needed; this is offline captured-trajectory admission. Base/SST whole-goal checks and mandatory meaning review are unchanged.

The collector attempts source-bound export for every retained per-case packet even after aggregate failedTests or cancellation. It never infers completion from aggregate progress names. This includes the actual outer done/result.returnValue.cancelled summary without progress. Unsupported/rejected interrupted packets retain their export-rejection evidence and remain unverified; queued cases without a packet are not admitted.

Validation: 135 Host collector/exporter/certificate tests; 203 Python reader/ingest tests; 63 Node tests (one existing opt-in archived-capture test skipped); quick ratchets/type check. Actual unchanged archived raw -> exporter -> Python NativeIR -> Node disk verifier/materializer: three captured calls, one eligible decision, task_completed=false. Forgery negatives cover original outcome/capture, native/input/output/contract/source bindings, missing proof, subtree effects and protocol downgrade. Local records are private test/derived evidence, never fake teacher samples.

Unchecked: automatic contracts for all other domains, new production reader deployment, and admission of a production automatic-partial cohort. Retained original packets support later independent contracts without rewriting history.
