# Reauthenticate legacy producer/consumer edge identities

The assembly stage retains complete protected trajectories. Its natural-language instruction is: normalize each authenticated read or Neuralese reference to its exact producer, consumer, writer name and body hash; when historical sidecars omit those identities, rederive all references in the affected trajectory from the unchanged native records. Preserve source provenance, exact exclusions and repair counts. Refuse a reconstruction that contradicts a prior concrete edge or loses an old producer/consumer pair.

1. Shared authenticated_recurrence_context_view remains the authority for native bodies and producer selection.
2. One crisp metadata extractor handles the two existing reference schemas. It performs exact field normalization and deduplication, without changing model-facing records or deciding source admission.
3. Conversion uses that extractor. Assembly invokes the same extractor after reauthentication only for trajectories with incomplete historical edge metadata; complete sidecars retain their fast path.
4. Receipts record repaired trajectory and edge counts. Independent graph verification reauthenticates whole retained chains before publication. Archive restoration and current held, quality, source-review and exact-decision protections remain existing mechanisms.

## Keep unresolved authentication out of otherwise valid chains

An independently reauthenticated real source chain contained an existing authenticate omission for one writer's input, but derive retained it because another row had a valid outgoing edge. The source artifact itself reproduces the failure.

1. Map explicit authenticate omissions back to whole source trajectories using exact record IDs.
2. Keep those trajectories assigned to source-context repair, including every original record, omission and edge in the immutable source archive. Exclude the whole unresolved chain from a trainable assembly, with per-record reason and failing IDs.
3. Apply the same mapping in new conversion and historical assembly before legacy-edge reconstruction. Independently valid trajectories continue through existing protection and graph verification.
4. This crisp verifier enforces the existing authentication contract; it invents neither producer evidence nor admission. Current source-review and exact held protections remain unchanged.
