Mechanism inventory: Host's archived packet includes actual NL return bytes,
player-view readbacks/actions, native final projection and independent protected
state/journal/sibling checks. Examples a4f's journey verifier rejected exact
opaque subject spelling/count after checking native facts. New Examples
findings.ts is shared by live native verification and this archived reassessor;
its player projection fact checker and independent-review rubric have one
implementation. Base's public entry now names JourneyFindings and the Host
binds its actual claims to native observations. Original historical API names
and bytes are preserved during recovery.

Existing recovery is recheck_live_trajectories.py recover: immutable original
packet/pins, source-hashed completed outcome, then load_episode, trajectory_ir
and the existing materializer. Shared validateWorkflowReview (renamed from the
Presentation-specific name without an alias) replays the exact captured judge
request/reply and requires the independent accepted verdict. Both Presentation
and Adventure use it. No serving/capture protocol or model engine is changed:
this tool consumes already captured provider calls through that same generic
recovery boundary and never calls a teacher or workspace. Engine adapters do
not implement task-specific Adventure verification.

The new reassessor covers unchanged explicitly compared queries whose assigned
save labels are unambiguous. It requires every original native guard to pass,
the sole failed check to be attestedAdventurePlayerEvidence, actual completed
root output/old entry binding, identical captured player snapshots, and native
facts matching the authored query. It refuses mutations, missing/changed
snapshots, unrelated return exclusions, held tasks and unbound source bytes.
It never invents an initial native snapshot. Only the exact root exclusion for
the mechanical evidence-match failure can be corrected after independent review;
original exclusions stay in the immutable original and bound correction evidence.
All original check names remain required, with required application returns.
