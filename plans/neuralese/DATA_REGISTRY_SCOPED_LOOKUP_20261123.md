# Registry glob ownership lookup

Inventory before edits: `common/data_registry.py` owns `Registry._lexical`, `_paths`, `_find_full`, `find`, `require_registered` and `consume`. `_paths` lists every first-wildcard directory and resolves every dataset root. Literal fast lookup avoids that; any matching glob currently sends a request back to the global index. A Vibe `capture/**` lookup consequently reads an unrelated external acquired-agent corpus before admitting its own input.

Shared consumers: `scripts/neuralese_data/sft_sources.py` calls `require_registered` for live campaign extraction and SFT build inputs; `live_campaign_ingest.py` uses that extractor; `filled_reasoning.py` calls `consume`; `grpo.py`, `teacher_gen.py`, `exp0_sft.py` and `pop_rl_actor.py` call `consume` for pool/model-training input provenance. `inventory_live_teacher.py` calls `Registry.find` directly. CLI `scripts/data_registry.py` and `sync_training_corpora.py` read the same registry. No serving engine implements this lookup: it is input admission before learner/actor invocation, shared independently of the serving engine (`docs/ENGINE_PARITY.md`). All callers retain registration and held/source-group checks; no consumer-specific bypass is introduced.

Implement metadata-derived ownership for glob prefixes. A first `**` owns its fixed prefix. A different first wildcard owns only the requested matching directory member, provided that member exists (including dangling symlinks, as directory enumeration previously did). Later pattern components retain the existing prefix ownership convention. Longest prefixes win; original admission/order ties, exact dataset-root ownership, and symlink fallback remain. `include_manifest` uses the same declared prefix conversion as the full index. `NATLANG_REGISTRY_SCOPED_GLOBS=0` selects the full original lookup for diagnosis.

Regression tests prohibit unrelated directory enumeration, compare scoped ownership with the full index for literal/mixed/recursive/wildcard/manifest patterns, preserve inventory rejection and protected/deeper ownership, and exercise aliases. This is not a relaxation of admission or a new benchmark.

Adjacent admission defect found and fixed: direct inventory dataset IDs bypassed the path-side admission check in both `consume` and `require_registered`. IDs now apply the same inventory rejection; the existing explicit allow-unregistered opt-out remains recorded. A regression covers both branches, admitted IDs, and annotated explicit opt-out.

Validation: ledger `registry-scoped-globs-tests-20261123b` passed 45 registry/ratchet tests (289 MiB peak); `registry-scoped-globs-quick-20261123a` passed source-review, 16 static ratchets, and TypeScript checking (963 MiB peak). Existing transient-file snapshot regression remains present and passed. This change has no dependency on newer serving/runtime code; a reader backport retains snapshot fix 2954170d4 separately.

Alias boundary: a query with no owner under any declared spelling retains the original resolving full-index fallback. Known declared glob ownership performs no unrelated filesystem access. The alias regression checks both querying a symlink to a registered target and querying a real target registered through a symlink; no registration/admission bypass replaces canonical resolution.
