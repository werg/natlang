# Complete acquired-session admission

The training service admits a complete declared source-file cohort for both
students as source-curated third-party SFT. It preserves failed sessions as
source evidence, never positive targets, retains whole-session and necessary
reasoning views, and carries the full global held closure across sources. It
does not wait for unrelated source conversion or assert native task execution.

1. Name the complete original archive cohort and both model views.
2. Verify immutable acquisition/export/conversion/frontier/output bindings.
3. Rejoin every native graph to the exact normalized source occurrence. Reject
   nonpositive sources, changed source groups, missing whole views, forged or
   duplicated reasoning views, current quality/pending/decision holds, and any
   train/held intersection. Parse the actual native graphs without truncation.
4. Emit one source manifest per model/split over aggregate files only. Shards
   are durability evidence and are never additional training sources.
5. Emit a reviewable registry proposal and byte-bound per-row admission proof.
   The independent supervisor reviews these before using the existing shared
   corpus registry/publisher. Registration is eligibility, not student exposure.

This is declared natural-language admission policy. Hashing, identity joins,
exact counts, native schema validation and immutable manifest writing are crisp
verifiers. Existing converters, source-group/decision-hold mechanisms and corpus
registration remain the sole implementations of their concepts.

## Connected source protection

Join all split-group keys of every normalized source occurrence, including failed
and omitted occurrences, with the existing split union-find. Propagate source
evaluation and current held, quality and pending protection through complete
connected components. A direct held-key union is insufficient: a row pulled into
held can connect further tasks through its other keys. Publish a new immutable
projection with the source component inventory; pending protection is closed
against the current review state whenever that projection is read. Admission
independently reconstructs the components from all bound normalized exports and
rejects an incomplete projection. Preserve original source splits and receipts.
Rebuild affected conversions; reuse unaffected numeric renderings only through
an explicit, checked protection continuation, never by changing their provenance.

The all-row audit authenticates source occurrence, provenance, target identities,
view completeness and native schema; it is not an independent token re-render.
A separate small qualification selects the first positive and largest complete
positive session per model, re-renders through the existing canonical
session_graphs mechanism with the actual pinned tokenizers, and compares every
stored graph token, weight, view and provenance value exactly. This is a source
render spotcheck, not a full-cohort re-render or a task-quality oracle.

After full source admission, partition complete ordinary rows against explicit
physical/KV envelopes without changing a byte of any row. The exact coverage
ledger proves the disjoint fit/remaining-long union and records every original
graph identity, binding and split. Limits are operational inputs, never a new
capacity qualification. Only the existing actual resident capacity certificate
may authorize appending the fit view. The long manifest remains a mandatory
source obligation; its declaration must feed existing native_continuation
progress/readiness rather than becoming a second exposure counter. This
integration remains open until the shared trainer/readiness contract is tested.
Preserve
earned credits when pending rows later become active, and never call the whole
recipe complete while any declared row remains owed. Foundation readiness may
still permit adaptive cross-model work while carrying all these obligations.
