# Carried offline objective closure

The declared recipe chooses the training objective. The provider performs only
exact file plumbing: for each incomplete mandatory native offline preference
frame, authenticate and transport its existing identity.objective path/SHA along
with the existing source receipts. The sidecar contains inline masks and objective
values; provenance strings inside it are not additional runtime file references.
Completed frames require no execution files. Missing or altered sidecars fail
before the provider can claim a complete input closure. No second source parser,
optimizer, objective implementation or training policy is introduced.

Validation: 17 provider closure tests pass, including real saved carried frames,
changed/missing sidecar rejection and completed-frame exclusion.
