# Actual owned stage output layout

The policy is to preserve real earned stage contracts when a manual ordinary
supervisor wrote its output under `learner` rather than the recipe runner's
stage-named directory. Missing conventional directories do not erase work.
No output directory or started marker is manufactured. Future recipe tuning
remains future-only and grants no exposure credit.

The crisp verifier authenticates the actual captured owner argv, exact stage ID
and output, full saved stage/options and positive exposure, and the closed native
training receipt's model, recipe, checkpoint and complete exposure inventory. It
snapshots that small receipt beside the existing immutable launch snapshots.
Only external native-state SFT owners use this seam. The existing lineage policy
receives the exact authenticated started ID; active input rewrites continue to
require its existing declared-continuation checks. All default paths remain as
before. Historical verification recomputes the same evidence and policy result.
