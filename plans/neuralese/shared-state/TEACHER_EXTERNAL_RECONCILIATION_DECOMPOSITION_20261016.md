# Reconcile actual teacher continuations

The supervisor keeps useful generation running while retaining unresolved work.
An interrupted original batch stays interrupted; independently executed retries
keep their actual actors and outcomes. No scheduling receipt admits training data.

1. Authenticate a transferred accounting snapshot and each original file before
   reading it. Reuse the collection continuation verifier for exact parent,
   actor/execution, packet/seed and metadata-history provenance.
2. Match continuation queue entries to original keys and all execution inputs;
   only output/job/log locations may differ. Authenticate each retry's start
   identity against its collection, then reuse existing batch-completion checks
   for terminal result and typed-budget accounting. Preserve unresolved keys.
3. Join terminal evidence by original key, retaining every collection's actual
   finish and exact snapshot binding. Terminal failure is not task success.
   Preserve original outcomes; do not synthesize worker exits or a batch score.
4. Verify an explicitly launched successor's transition, old-state bytes,
   configuration, feeder, live process/token and teacher identity. Preserve an
   immutable original boundary and prepare retries only for still-unresolved
   keys; adopt the existing successor rather than launching it twice.

Policy remains the existing teacher supervision instruction. Hashes, exact
identity joins, process verification, atomic state publication and transport are
crisp mechanisms. Both students use the same admitted teacher data; no model
prompt, reward, scientific clean-run requirement or new sandbox is introduced.
