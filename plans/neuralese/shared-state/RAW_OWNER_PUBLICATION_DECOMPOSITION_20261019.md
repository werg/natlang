# RAW owner publication binding

Policy remains in the existing natural-language stage and RAW controller: each
completed trainer operation publishes an observation for its actual model role.
The publication helper is exact durability plumbing. It binds the configured
role, the Python package that supplied the running trainer, the expanded trainer
argv, selected parent, and writer directory. A RAW controller's `runtime` can
name its TS orchestration runtime, so the publication package root is an
explicit operational field; it is checked against `NATLANG_REPO` in the exact
expanded child command. No trainer arguments or learning objectives are
rewritten. The observer repeats the same command and output-bound checks before
exporting a full checkpoint.

The semantic participant field remains reserved for semantic participant
identity. RAW publication role is carried separately and is never written as a
participant. The writer directory may be nested under the exact operation
output root, but cannot escape it. The publication manifest is an observation
and grants no training or qualification credit.

| Part | Representation | Reason |
|---|---|---|
| Role and runtime selection | Explicit controller metadata | RAW role and TS runtime do not identify the Python model package. |
| Command parsing and path checks | Shared Python verifier | Exact argv, parent, package origin, and filesystem containment. |
| Generation publication | Existing atomic immutable writer | Crash-safe owner pointer and immutable generation. |
| Training decision | Existing natural-language recipe/controller | Publication does not select tasks or alter training policy. |
