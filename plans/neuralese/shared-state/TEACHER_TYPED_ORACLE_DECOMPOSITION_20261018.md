# Exact typed source-oracle dispatch

The authored natural-language functions remain policy. Source-owned oracle answers are fixed evidence, not generated targets. The crisp checker must route an answer only to a child whose actual native return contract accepts its shape. A Decision string is not an answer to a boolean child; returning it repeatedly creates an unbounded scripted recovery loop.

1. A scripted driver explicitly requests a host-only native result-contract check through existing turn options. Ordinary drivers retain their current options and model inputs.
2. The native agent closes that check over this exact session's return type/environment and uses existing coerce + complete-value checks. This is structural validation; existing runtime refinement/semantic gates still apply to selected answers.
3. Match unchanged source oracle fragments as before, then filter only by the exact contract. Keep original ordering and conflict rules within the eligible candidates. Do not infer predicates, coerce string decisions to booleans, change source runs, or rewrite captured outcomes.
4. When no source answer fits, use the existing no-answer failure. It remains harness-uncovered assigned repair, not a model failure or acceptance. No new model-facing wording or payload is added.
5. Test actual compiled authoring with boolean/Decision, literal unions, incomplete records, concurrent different child types, unchanged reference success, and unchanged ordinary-driver options. Recheck original captured TRAIN rows separately; only exact ALL-run expected results can recover a row.

This does not make uncovered semantic oracles complete. Independently declared source routes or actual own-teacher child execution are required for those remaining repairs. Existing 24-case/48-trajectory compiler-repair measurement work also covers the resulting execution behavior; no new external generation or GPU process is authorized here.

Validation: 19 actual authoring/typed/ambient tests and 26 transport/routing/streaming tests pass; quick ratchets/TS checking pass. All 16 captured TRAIN compiler cases terminate under the new checker: one preserves exact ALL-run source results, fifteen remain no-answer harness repairs, and none reaches the diagnostic watchdog. Historical raw rows remain unchanged. Native ordinary-driver request/options tests confirm no new model input.
