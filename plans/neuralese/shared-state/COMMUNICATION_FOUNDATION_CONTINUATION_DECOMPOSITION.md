# Communication foundation and mandatory continuation

## Policy

Train every admitted production source on both models. Genuine communication
training is the foundation for cross-model adaptation; an evolving ordinary
corpus must not postpone that adaptation indefinitely. A foundation boundary
therefore requires every quota of the currently declared complete admitted
communication cohort, plus actual held/task/runtime checks at those exact
weights. It is not full stage completion. Ordinary deficits remain mandatory,
are carried through VAE/joint/distillation/RL, and return to supervised training.
An empty structural import provides no communication credit. New admission
extends mandatory exposure and the next explicitly declared cohort; it cannot
erase the completed foundation while that next cohort is still pending. A tiny
earlier shard cannot stand in for a larger currently declared foundation.

## Functions and exact mechanisms

1. **Select the foundation** is the declared recipe/curriculum policy, naming
   the complete admitted communication source/cohort. Exact manifest/row and
   quota checks are crisp verifiers; passing a short step count is insufficient.
2. **Track mandatory supervised progress** uses one shared continuation frame
   per declared CE stage. Preserve immutable row/held bindings, source order,
   quotas, actual credits, cursor and metrics. The current optimizer, FP8 and
   RNG stream remain with the participant; do not duplicate old optimizer/RNG
   snapshots in every frame or restore historical RNG after joint training.
3. **Cross an objective boundary** preserves those frames per participant in
   the shared checkpoint. RL carries CE frames unchanged. Returning to a CE
   stage selects its frame, checks append-only bindings/order, and consumes
   remaining visits with the current optimizer/RNG instead of resetting credits.
4. **Publish foundation readiness** binds its exact checkpoint, cohort exposure,
   remaining mandatory deficits and actual checks. Formal `completed` remains
   false until every declared source quota is done. Rendezvous admits explicitly
   foundation-ready models without forging full-stage completion.
5. **Keep supervised work executable** makes remaining CE obligations part of
   subsequent/interleaved production scheduling, rather than a manual note.
   Each boundary records the current row-level credits and exact checkpoint;
   semantic adapters are refreshed after any model-weight change before reuse.
6. **Verify end to end** includes interruption, repacking, source append,
   foundation-to-shared-to-RL-to-CE restoration and exact moments/RNG. Numeric
   and runtime checks protect real behavior; base-relative drift is telemetry.

## Declared interleaving

The operational refresh quantum is the recipe's existing checkpoint step/time
cadence (`refresh_at_checkpoint`), ending only after a complete graph update.
A partial CE continuation carries `completed:false` and a bound
`continuation_boundary` with actual new optimizer updates. Task/runtime checks
still bind those exact weights before merging, and the whole supervised quota
remains mandatory. One quantum per declared CE stage runs through the existing
round bridge/seed command, then the same joint adapter refresh, before returning
to RL. A durable stage cursor prevents replay after a publication/restart.

New raw communication admission is compared with exact paired-source index row
bindings and participant credits. Until both models finish the complete new
cohort, semantic refresh uses its previous qualified source membership, keeping
current tuning and explicitly retaining the requested pending curriculum. The
adapter carries that exact qualified config inline and its canonical SHA.
Initial semantic training has no prior-cohort fallback and must have actual raw
exposure for its complete requested cohort.

## Adaptive semantic refresh

Keep cumulative phase/source/pair exposure when participant weights change;
recompute current KV targets using actual current models. Initial and later
publications may execute declared finite work in all VAE, joint/control and
distillation phases, provided current held/task/native/compact cross-model
transport checks pass. This is explicitly `refresh_ready`, with `completed:false`
while full production exposure remains unfinished; it is no claim of Neuralese
lift. Exact declared raw communication foundation remains mandatory first.

Use declared `adaptive_refresh.updates_per_phase` (optional
`phase.options.refresh_updates` override) for useful work in every phase. The
initial operational production setting is 16 whole-graph updates per phase,
not a curriculum completion budget. Advance durable per-phase source cursors;
prioritize remaining quotas, then continue adaptation without erasing visits.
Preserve optimizers/RNG and operational refresh progress across stops. The next
publication resumes remaining phase work rather than restarting its quantum.

Use declared `held_eval_rows` (initially 32) for rotating whole held graphs,
with source, cursor and row visits persisted. A full held sweep is mandatory
when the complete curriculum first finishes, and after source/quota extensions
finish; subsequent partial adaptations measure current rotating slices instead
of repeatedly sweeping all held rows. Formal completion only describes the
actual full current exposure and full held result at those weights.

Native task execution binds the learned channel to live models through the same
helper as actor loading. A separate compact-wire certificate exercises all
cross-model directions against direct learned decode and positional splice,
including next-token KV/convolution state. It proves transport parity, not useful
communication or task improvement. Preserve the stable adapter SHA throughout
these checks; persist receipts separately rather than rewriting the adapter.

The existing joint controller consumes pending semantic obligations even when
there is no new rollout update, using the same refresh bridge and publication
transaction. Remaining supervised obligations continue interleaved through the
existing CE path. Neither empty rollouts nor an initial refresh ends the recipe.
Actual SDK worker qualification and independent integrated review remain open
before production controller deployment.

## Standalone semantic continuation

The policy is the same declared comprehensive curriculum: if no RL bootstrap is
configured, continue successful finite semantic publications until their actual
phase/source quotas finish. Do not turn partial success into a terminal stage.

1. Verify the successful report and persist its immutable publication binding
   in controller state. Recovery may discover a valid child report written just
   before its supervisor stopped. An exit code alone never grants publication.
2. If quotas remain, derive one next output directory from the exact parent
   publication. Pass its checkpoint, adapter and report in `semantic_parent` in
   the existing participant manifest. Keep the previous successful output intact.
3. Use the existing supervised child launch/ownership/stop/recovery mechanism.
   Bind that child's completion path in its durable launch record so a restarted
   supervisor watches and validates the same work. Commands declare `{out}` and
   `{participants}` placeholders for per-cycle destinations.
4. The shared trainer verifies the parent, restores full model/VAE/optimizer/RNG
   state and credits, and includes that parent binding in its operational cycle
   identity. A new parent starts new finite work; retrying an interrupted child
   resumes that same cycle rather than replaying completed updates.
5. Each phase starts pending-row search at its existing durable source cursor
   and wraps to find older, increased or newly appended quotas. No ordered prefix
   scan repeats for every update. Current KV is recomputed from current weights.
6. Publish only after the same actual current checks. Continue until actual
   full exposure and mandatory full held evaluation complete; subsequent restart
   observes that publication without relaunching finished work.

This is one shared trainer and one child mechanism. The controller's crisp code
verifies exact artifacts, chooses deterministic durability paths and applies
the already declared continue-until-quotas-complete policy. It introduces no
separate optimization objective, new science barrier or arbitrary training cap.

Checkpoint continuation metadata stores only parent content identities, not a
recursive path dependency on all historical full-model checkpoints. The current
parent's full bindings are explicit participant-manifest launch inputs. Keep the
last successful parent while its child is unfinished; an independently loaded
current actor remains self-contained. Curriculum/source/participant changes
recompute semantic obligations once; each committed graph then subtracts only
its actual newly consumed pair visits. Final proof recomputes the whole ledger
exactly. This avoids a second full-corpus scan on every optimizer update.
