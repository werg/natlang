held closure leaves their exact source groups and splits unchanged. Affected
rows require rebuilding; no protection is released. This continuation grants
source eligibility only, never numeric re-rendering, execution or exposure.

1. A supervising natural-language stage selects the already passed original

2. The crisp verifier authenticates their immutable files, reconstructs the

3. It streams the small original audit row proof, checking exact IDs, splits,
   group membership and graph identities, and hashes the already bound numeric
   aggregate files without parsing tokens or running a model. All conversion
   receipts, resume metadata and omission files remain exact.
4. It durably publishes a new certificate. A capacity proposal may explicitly
   attach this certificate and new protection evidence while preserving the old
   numeric audit, partition, row identities and zero-credit long obligations.
   The registry supervisor independently reviews this result before admission.

there is no new learned admission policy or model-facing change.
