# Continuing unaffected admitted numeric cohorts

Policy: retain useful admitted rows when a stricter, complete connected-source
held closure leaves their exact source groups and splits unchanged. Affected
rows require rebuilding; no protection is released. This continuation grants
source eligibility only, never numeric re-rendering, execution or exposure.

1. A supervising natural-language stage selects the already passed original
   audit and exact old/new protection projections.
2. The crisp verifier authenticates their immutable files, reconstructs the
   complete new source closure through the shared closure verifier, and requires
   monotone held groups and identical quality, pending and decision policies.
3. It streams the small original audit row proof, checking exact IDs, splits,
   group membership and graph identities, and hashes the already bound numeric
   aggregate files without parsing tokens or running a model. All conversion
   receipts, resume metadata and omission files remain exact.
4. It durably publishes a new certificate. A capacity proposal may explicitly
   attach this certificate and new protection evidence while preserving the old
   numeric audit, partition, row identities and zero-credit long obligations.
   The registry supervisor independently reviews this result before admission.

The verifier and proposal attachment are exact durability/protocol plumbing;
there is no new learned admission policy or model-facing change.

## First complete audit after a protection correction

A cohort without an earlier passed audit cannot inherit a fictional one. The
full source-admission verifier accepts an explicit `--conversion-protection`
for the old numeric receipts, alongside the current `--protection`. It uses the
same transition verifier, requires complete current global closure, and checks
EVERY original source occurrence (including omitted failures) has unchanged
eligibility and split. It then performs the normal complete graph/source,
view/target, mask-bearing output, receipt, runtime and decision-hold checks.
The new audit records both protections and bundles exact portable projection
evidence; conversion receipt bytes remain untouched. Existing source-backed
sample qualification re-renders its exact selected full views without a special
or weakened path. Later continuation certificates understand this original
numeric provenance separately from the audit's current eligibility proof.
