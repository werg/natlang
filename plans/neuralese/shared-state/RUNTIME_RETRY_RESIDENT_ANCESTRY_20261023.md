# Runtime authority across a completed retry

The natural-language supervision policy is to continue the latest earned state after an authenticated pre-update repair. A retry replaces the resident root recipe, so direct membership of the older runtime recipe in the new resident journal is insufficient.

The crisp verifier accepts the existing direct ancestry, or the existing fully verified no-credit retry receipt. The latter must have been consumed into the actual cursor history, inherit the exact runtime authority and lineage, and bridge the exact old recipe to a recipe in the resident history. It changes no weights, optimizer, RNG, exposure, cursor or data. Frozen controller and publisher closures must load this shared fix before deployment.
