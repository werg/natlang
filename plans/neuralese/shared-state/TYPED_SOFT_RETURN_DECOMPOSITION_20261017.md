# Authenticate callable Neuralese returns from recorded teacher trajectories

Natlang operation: preserve a successful typed callable return and its complete
producer/consumer trajectory when the runtime turns an authored instruction
span into a typed Neuralese value. Policy remains the existing source-quality,
whole-trajectory and protected-split admission rules.

1. Read the exact sampled return action and its invocation's completed output.
2. Verify the declared callable Neuralese type, identical host type/reference,
   exact singleton transport reference, and unique terminal action.
3. Verify the same invocation and current model turn wrote that exact block,
   with the complete authored body's hash and causally ordered trace edges.
4. Preserve original sampled arguments as the target; link only authenticated
   runtime outcomes. Mutated, truncated or ambiguous evidence stays rejected.
5. Run the complete source through the existing materializer and both native
   converters; retain any concrete unsupported graph obligation explicitly.

All five steps are exact recorded-data verification, so they extend the crisp
existing materializer rather than adding a model policy or changing prompts.
Legacy string-return behavior and ordinary strings retain their current
contracts. This does not authorize importing legacy projected state at native
inference; text trajectories are converted to the current token/state format.
