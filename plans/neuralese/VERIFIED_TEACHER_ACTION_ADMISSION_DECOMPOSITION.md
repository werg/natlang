# Verified teacher action admission

A successful program can contain rejected actions, seeded failures and recovery.
Its outcome qualifies the execution, while the existing native materializer
decides which individual actions are useful positive imitation targets.

1. Verify the stronger teacher's immutable source, actual response files, own
   program packet, exact successful outcome and current source protections.
2. Run the existing native teacher materializer on those original trajectories.
   Reuse its failed-action, execution, coercion, repetition and checker decisions;
   do not implement a second action reviewer in the graph converter.
3. Bind that output to the exact input bytes and executing materializer assets.
   Share the resulting admission index between both tokenizer conversions.
4. Render only admitted, source-bound original assistant actions. An injected
   seeded turn with no provider response must never become an empty positive
   reply. Keep every original context, including failed actions and recovery
   feedback, in later examples at the declared lower context weight.
5. Record every unqualified turn with its original trajectory/turn identity and
   the materializer's reason. Keep reusable original evidence; do not relabel
   failures or invent tool calls.
6. Audit already emitted graphs against the same admission index. Withdraw
   proven bad positive targets through an explicit source-bound continuation;
   retain consumed exposure history, optimizer/RNG and all good-row obligations.

The policy above is natural language. Crisp code supplies the existing CLI,
exact hashes, durable cache/lock, source joins and graph rendering. The original
teacher materializer remains the single decision implementation.

Exact capture joins require a nonempty original invocation and lowercase 64-digit
SHA-256 request/response hashes. Missing or malformed capture identity omits only
that turn, while a conflicting bound invocation/response still rejects the input.
This converter has no legacy missing-capture fallback.
