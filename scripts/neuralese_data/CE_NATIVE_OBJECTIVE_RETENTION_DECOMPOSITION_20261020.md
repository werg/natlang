Policy: change only the authenticated raw ordinary-suffix and witnessed-pair encodings. Existing direct native graphs carry explicit per-node target masks and retain that objective. Source registration or policy inventory is not training exposure.

1. Crisp first-row classifier: match runtime eligibility, while rejecting malformed partial legacy markers. For a direct native graph with no legacy encoding markers, use the shared graph-field validator to authenticate explicit node masks, token IDs, groups and references without compiling KV positions. Record its exact source SHA and retained-objective reason; do not infer a suffix or coefficient.
2. Crisp guards: preserve exact source hashing, schema/split checks, model-view compatibility and all normal eligible declarations. Every consumed row still passes the runtime's required eligible-source coverage; a later eligible row cannot hide behind a retained first row.
3. Tests: real first-row JSONL sources and semantic model views, exact unchanged node weights/identity at runtime, corrupt masks and malformed eligible markers, mixed model-view encoding conflict, and later-row coverage rejection. No intrinsic parser/index file or numeric trainer changes.
