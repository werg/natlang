# Exact verified children from partial teacher outcomes

The owner policy is to retain independently correct decisions from partly rejected trajectories. The parent task remains held. A verified child result never changes its parent's grade, expected target or raw capture.

## Policy as named stages

1. **Authenticate original evidence.** Read the exact admitted-source custody and held-row inventory. Authenticate the pinned primary SST archive, full sentence membership, original TRAIN split and declared source label. Reject conflicting or missing source evidence; do not infer labels from model output.
2. **Identify a typed child.** Require a completed, non-root child invocation with an exact host-attested FileHandle opening and captured declarations, full original file bytes and the declared positive/negative return contract. Require its host result and original provider terminal action to equal the independent source label. Unknown or truncated bindings remain unresolved.
3. **Select exact decisions.** Emit review candidates binding original row/turn/invocation/request/response/target and source proof. Root actions and wrong/unverified children remain excluded. Candidate discovery grants no admission.
4. **Reuse decision authority.** Use the existing native decision review and materializer interfaces. Only explicitly approved exact decisions may pass the partial-parent branch; an approval must not release siblings. Preserve source quality, held split and runtime checks.
5. **Preserve context and masks.** Keep complete original invocation context and captured target. Exclude unverified assistant targets from loss. Reuse existing graph conversion and explicit weights; do not silently train a wrong earlier target at reduced weight. Both tokenizers retain their own serving renderer/profile identity.
6. **Validate and publish.** Reauthenticate current global protection and original source/oracle bindings, complete emitted/held action conservation, exact BOTH source-action identity and zero prior graph overlap. Actual registration/staging grants no exposure.

## Crisp mechanisms

SHA/type/byte comparisons, exact capture joins, durable receipts, token masks and the existing CLI/materializer/converter plumbing are crisp because they verify the declared policy. No new generation or model-facing text is introduced. No whole failed task is marked passed. New positive training requires an explicit independently reviewed decision-level proof and current protection.

## First evidence gate

Inventory the actual thirteen held rows from three disjoint tranches before extending training admission. Tests must reject wrong labels, root invocations, mismatched file bodies, incomplete or conflicting host results, target/request/response mutations, wrong protection and sibling approval leakage. Preserve legacy conversion bytes when no review is supplied.

## Admission mechanism and preserved defaults

The existing native decision approval gains an optional `parent_quality_hold` naming only the two actual partial-quality states. It must match current materializer policy. Such a parent is counted separately as partial, never accepted; only exact reviewed non-root children may train. Every unapproved sibling has both training and trace admission disabled, even when the historical outcome says `accepted=true`. Normal decision approvals and default conversion remain unchanged.

The shared `text_row_graph` optionally masks all preceding assistant tokens, including reasoning, while retaining their exact IDs as causal context. System/user/tool context retains its normal lower weight, and the exact independently reviewed suffix retains full weight. This reuses the common chat-role parser; unsupported or ambiguous role/boundary layouts fail closed. Both tokenizer/render profiles are checked with actual captured inputs before publication. The decision-review file SHA is part of the existing source/runtime materialization cache identity and is checked again after execution.

Discovery bindings include the verbatim realized instruction and captured variables. The independent supervising agent reviewed all 27 actual template/capture combinations in the 192-candidate inventory; that semantic review is evidence only. Revalidate every original source/input/provider/host join and current protection before assembling the existing decision-review file. Neither a template approval nor this discovery alone grants corpus admission.

Before role-based masking, inspect the original structured messages, raw tool arguments/schemas, target and capture plus resolved text-emulation inputs. Embedded renderer-owned ChatML boundary markers make the decision explicitly pending; token-stream role labels cannot distinguish them from real framing. Bind this input-guard proof into the mask and independently recompute it from the original source in final admission. Legacy unreviewed conversions retain their existing policy.

## Historical default conversions across the explicit extension

An already-sealed default conversion keeps its original materializer receipt and graph bytes. A continuation may bind a fresh current default materialization only when the complete decisions output SHA/bytes and every typed summary field are identical. Authenticate both receipt/output files, exact source SHA and the entire current runtime before/after verification. Decision-review identities cannot use this default-only continuation. The proof grants no admission; current source, split, held, graph and accounting checks still run. This avoids reconstructing historical source or rerendering unchanged graphs just because an unrelated optional branch was added.
