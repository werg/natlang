The supervisor's quality decision names exact ordinary targets and preserves all
other training obligations. No global split policy changes. Existing withdrawal
verification owns saved-credit/history handling at an authorized continuation.

1. Authenticate the old source SHA and enumerated target IDs/bindings from its
   completed source index. Stream the source once, remove only those exact IDs,
   and preserve every other raw byte in order. This is crisp data plumbing.
2. Independently decompress/read back the new source and compare the complete
   retained-byte digest. Publish the completed immutable file without replacing
   a concurrent destination. Record all removed raw row hashes and ID order.
3. An optional index continuation authenticates the exact old own-cache bytes,
   full metadata digest, source/key and original ID order. Remove only the same
   entries/bindings; retain every other metadata value and the parser/tokenizer
   policy exactly. Reuse existing atomic no-clobber index publication.
4. This creates a source replacement, not appended duplicate data or admission.
   The existing ordinary withdrawal proof, actual predecessor, optimizer/RNG,
   credits and recipe authority remain mandatory. No live mutation is implied.
