# Exhaust the next reference work without replacing current teacher batches

The supervisor declares an immutable source candidate proof and an existing
ordered candidate/readiness prefix. The next work is every remaining candidate,
without a corpus, family or total cap. A finite packet is a work unit, not a
selection cap. Known conflicting identities and protected occurrences stay
explicitly unready. An unchanged program becomes ready only after the existing
bound reference qualifier succeeds; reference execution is not generation,
training admission, exposure or proof of teacher success.

1. Authenticate the original candidate bytes and every prefix packet.
2. Subtract the prefix's exact canonical program hashes.
3. Resolve those remaining programs in one read-only catalog snapshot. Retain
   conflicts or protected occurrences as named pending obligations.
4. Follow the existing file/family round-robin order and exhaust the remaining
   original programs in finite work packets, preserving source occurrences.
5. Invoke the declared existing qualifier with its exact bound bytes, resuming
   completed proofs. Extend readiness only in the declared candidate order.
   A zero-qualified packet blocks that readiness prefix, but qualification of
   later work continues and its proofs remain explicit rather than omitted.
6. Independently review new declaration/assets before teacher adoption. Existing
   prefix files, current batch, actor, runtime and guardian stay untouched.

This policy is natural language. SHA joins, exact set subtraction, SQLite
snapshot iteration, finite work serialization, bound subprocess execution and
atomic receipts are crisp mechanisms. The tool reuses the existing qualifier
rather than duplicating reference, split or admission decisions. Disk reserve
is the owner's existing 20 GiB floor; work remains resumable if it is reached.

The existing exact packet verifier gains an explicit `allow_empty` diagnostic
option. Guardian selection retains its default rejection of empty task packets.
The append worker uses the option only to authenticate all original verdicts and
an empty complete qualified subset before recording unready work. It does not
publish that packet as ready or skip its obligation. A per-output lease prevents
concurrent append writers. After interruption, only allowlisted derived files
without a prepared envelope are regenerated; their exact hashes are recorded,
while original inputs and fsynced per-program verdicts remain untouched.

The actual first external-disk preparation spent its time in cold SQLite reads:
its query plan scanned `programs` and evaluated correlated eligibility before
checking the finite selected set. Both eligibility and ranking now force the
selected set first with an exact cross join; predicates and per-source ordering
are unchanged. The known-unready list explicitly retains original row order.
The original readonly attempt had no packet output, was stopped by its exact
unit, and retained its mechanism/spec/headers for this assigned diagnosis. No
catalog snapshot copy or source mutation is needed.
