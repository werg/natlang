# SST2 task context custody

The policy is to ask the teacher about complete, source-backed reviews. A phrase
label is not the label of its unseen parent sentence. Preserve historical source
labels and tasks; correct context through new explicit program derivatives.

1. Acquire the original Stanford Sentiment Treebank sentence/split files through
   the existing pinned source archive mechanism. This is outside-world plumbing.
2. Verify both exact member hashes and parse the source sentence/split relation.
   Match only whitespace-normalized, case-folded full sentences in the original
   train split to the existing SST2 train records. This is an exact source-format
   join, not a punctuation/length heuristic or subjective sentiment decision.
3. Both labeled-source loaders use this same verifier; folder, labeled-judgment,
   cross-source and workbench task builders preserve host-only context bindings
   (including replacement-world rows). Model input construction stays unchanged.
   Select eligible records through the existing sampler and source split/held
   policy. Keep existing record IDs and labels. Attach original sentence IDs,
   raw context/member/source hashes and the declared matching rule to each chosen
   record's program provenance. Missing context must fail with acquisition advice.
4. Audit historical task/decision references separately. A failed membership check
   is review evidence, never a silent historical relabel or blanket family ban.
   Corrected tasks retain original and replacement source groups and receive
   independent reference/protection checks and fresh teacher trajectories.
